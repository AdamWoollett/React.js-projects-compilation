This respository contains a number of smaller projects I completed whilst learning React.js. They are each confined to their own folders.

"Module 2.2 Building reusable card component" is a project where I create a reusable component that is used 3 times to display basic information about 3 different mobs from the game Minecraft.

"Module 2.3 Variables" is a project where I tested out displaying variables of different types on a page. The String Variable line has a randomiser that chooses between 2 strings to display on page load. Number Variable displays a number, Array Variable displays an array. The 3 Object Variables each display a single object property from an object. "This is some more JSX" comes from a function defined outside the JSX section in the file. The list of fruits also comes from a function that maps out all the items in an array to be displayed.

"Module 2.4 Dynamic Job Board" is a web application containing various interactive and dynamic displays. Job Board of JobDoers updates what message it displays depending on the size of the number specified in the file. The next section contains a button that disables itself when clicked. Job Counter displays a number that increases with each button press. Advanced Job Counter allows the user to change the number of jobs assigned to 2 different environments. Dynamic Input form allows a user to add strings to a list using the buttons. Bot List Manager has 3 bots whose state can be updated by pressing "Trigger Job". Dynamic Bot List Manager displays a list of bots from an array, and allows the user to add and remove their custom bots from the array.

"Module 4 Modular Job Board" contains 2 versions of a Job Board application. The first half has all the jobs added to a single toggleable list, which can have jobs addded or removed and dynamically chooses a colour based on status. The 3 coloured boxes below are static status boxes made using reusable components, with a toggle to display more info. Below that is Job Board version 2 which allows a user to create custom jobs which can have multiple categories assigned. The form does not allow submission until valid inputs are created in all fields. Submitted jobs are auto-soted into 3 category boxes, which provide the user the ability to move jobs between status categories and delete jobs. The list at the bottom stores a record of all jobs the user has added in the session, even if they delete any.
